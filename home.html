تقنيات مقترحة

  • الواجهة: Next.js أو React مع Tailwind CSS لتجربة مشابهة لـ Target.
  • الخلفية: Node.js (NestJS) أو Laravel مع قواعد بيانات PostgreSQL.
  • البنية: API-first و GraphQL/REST لدعم تطبيقات الجوال لاحقًا.
  • الأمان: بوابة دفع موثوقة، مصادقة متعددة العوامل، وحماية ضد الاحتيال.

منصة النشر

  • الاستضافة: Vercel أو Netlify للواجهة، مع إمكانية استخدام AWS أو DigitalOcean للباك-إند.
  • التدرجية: بنية سحابية قابلة للتوسع مع CDN لتسريع التحميل في المنطقة.
  • التطبيقات: بناء تطبيقات React Native أو Flutter مرتبطة بنفس الـ API.
